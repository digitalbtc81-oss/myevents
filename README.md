# Events

Events is a WordPress plugin that adds an events calendar. Create events in wp-admin and show them on a page or post with the shortcode `[myevents]`.

The plugin directory name is `ekdiloseis`. Install it at `wp-content/plugins/ekdiloseis/`.

Updates come from GitHub releases of [digitalbtc81-oss/myevents](https://github.com/digitalbtc81-oss/myevents). A site that has the plugin installed checks those releases and offers the update on the WordPress Plugins screen. Each release archive is named `ekdiloseis.zip` and its top-level directory is `ekdiloseis/`.
